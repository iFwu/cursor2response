# Roadmap

- Improve context accounting to distinguish per-request, cumulative Run, and
  current SDK context measurements.
- Expand Codex and OpenClaw coverage for parallel tool batches, cancellation,
  steering, and recovery after an interrupted Run.
- Validate Docker on additional platforms beyond Linux amd64.
- Reassess endpoint-specific Chat Completions and Anthropic Messages support
  after the primary Responses workflows.

Current behavior and compatibility limits are documented in the
[README](README.md) and [protocol contract](docs/specs/protocol-support.md).
